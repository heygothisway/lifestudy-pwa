# 生命讀經追求排程器 (PWA) 🌱

為生命讀經共同追求群組設計的排程工具：輸入書卷與篇數，自動把兩篇信息各分成三段，排成 6 天的追求進度，並可一鍵複製貼到 LINE。

**線上使用：<https://heygothisway.github.io/lifestudy-pwa/>**

手機與電腦都能直接開啟，也可安裝到主畫面。

---

## ✨ 功能

- **書卷選單**：舊約在前、新約在後。撒母耳記、列王紀、歷代志各合併為一卷（簡稱「撒」「王」「代」），篇數分別為 38、23、13 篇。
- **智慧分段**：把每篇信息依小綱目與字數分成三等分，產出「到『…』前」與直達連結。
- **沒有綱目的篇章**：改按字數三等分，切在段落開頭，並用該段開頭約 10 字定位。連結使用「文字片段」格式（`#:~:text=…`），開啟後會自動捲到並醒目標示該段。需要較新的瀏覽器（Chrome、Edge、Safari 16.4 以上、Firefox 131 以上）；不支援時只會開到頁首。
- **週期與無共追日**：
  - 可設定「當週第一篇起始星期」。
  - 可設定「每週小排無共追日 (不發提醒)」。
  - 選擇的起始日期若不是起始星期，會自動往後對齊到起始星期。
- **篇數限制**：
  - 切換書卷時，篇數自動回到第 1、2 篇。
  - 篇數不會超過該卷總篇數。
  - 本週第二篇超過總篇數時，只排第一篇的前 3 天。
- **一鍵複製**：複製完整排程或單日內容。「下週／上週」按鈕可快速切換進度。
- **記住設定**：書卷、篇數、週期與抬頭文字都會存在該裝置的瀏覽器。
- **離線可用**：生命讀經頁面已內建在 `data/`，不需要連到外部網站。
- **選用：縮短連結**：在「自訂群組發文抬頭」區塊填入 reurl.cc API 金鑰，文字片段連結會自動縮短。金鑰只存在該裝置的瀏覽器，不填則使用完整連結。

## 📱 安裝到手機或電腦

- **iPhone / iPad (Safari)**：分享 → 加入主畫面。
- **Android (Chrome)**：選單 → 安裝應用程式（或加到主畫面）。
- **電腦 (Chrome / Edge)**：網址列右側的安裝圖示。

更新後若仍看到舊版畫面，請重新整理一兩次，或移除後重新安裝。

---

## 💻 本機執行（選用）

需要 Python 3：

```bash
python server.py
```

或在 Windows 雙擊 `啟動生命讀經排程器.bat`，瀏覽器會自動開啟 `http://localhost:8080`。同一個 Wi-Fi 下的手機可用電腦的 IP（例如 `http://192.168.1.xxx:8080`）連線。

---

## 🚀 部署

專案以 GitHub Pages 發布（`main` 分支根目錄）。推送到 `main` 後約一兩分鐘自動更新。

修改程式後，請把 `sw.js` 中的 `CACHE_NAME` 版本號加一，讓使用者取得新版。

---

## 📁 檔案結構

| 路徑 | 說明 |
| --- | --- |
| `index.html` / `style.css` | 介面與樣式 |
| `app.js` | 排程、分段演算法、設定記憶、縮網址 |
| `books.js` | 66 卷書目資料（合併後 63 卷）與網址規則 |
| `data/` | 內建的生命讀經頁面（`{書卷編號}_{篇數}.html`） |
| `manifest.json` / `sw.js` | PWA 安裝與離線設定 |
| `icons/` | 應用程式圖示 |
| `server.py` / `啟動生命讀經排程器.bat` | 本機伺服器與啟動檔 |
