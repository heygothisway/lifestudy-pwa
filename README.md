# 生命讀經追求排程器 (PWA) 🌱

專為服事聖徒與生命讀經共同追求群組設計的排程自動化工具。

---

## ✨ 核心特色

1. **聖經 66 卷新舊約完整收錄**：
   - 預載全 66 卷生命讀經書卷名稱、官方簡稱（如：`創`、`西`、`羅`）與篇數。
2. **智慧三等分綱要切段**：
   - 即時連線福音書房官方生命讀經頁面（`line.twgbr.org`），自動分析各綱要節點與字數，求出最均勻的三分點。
   - 自動抓取官方小標題與錨點（如 `#O3`, `#O5`），準確產出「到『...』前」與直達連結。
3. **彈性週週期與休息日（支援休息日在中間）**：
   - 可自選「起始星期」（例如：主日開始、週三開始）。
   - 可自選「哪一天休息不推」（例如：週三小排日無共同追求，週四接續第 2 篇；或週二事奉禱告日休息）。
   - 自動將週日格式化為召會通用的 **`(主日)`**。
4. **一鍵複製與記憶功能**：
   - 記憶上次選擇的書卷、已讀篇數與週期設定（下次開啟秒載入）。
   - 提供「📋 一鍵複製 6 天完整內容」與「📋 複製今日」。
   - 提供「⏭️ 下週 (+2篇)」快速切換按鈕。
5. **支援 PWA 手機安裝到主畫面**：
   - 手機 Safari 點擊「分享」→「加入主畫面」，或 Android Chrome 點擊「安裝應用程式」，即可如原生 App 般在手機上秒開使用。

---

## 🚀 啟動方式

### 電腦端一鍵開啟：
- 直接雙擊執行專案目錄下的 **`啟動生命讀經排程器.bat`**。
- 或在終端機執行：
  ```bash
  python server.py
  ```
- 瀏覽器將自動開啟：`http://localhost:8080`

### 手機端使用（區域網路 / 熱點）：
- 當電腦啟動 `server.py` 後，手機只要與電腦在同一個 Wi-Fi 網路下，用手機瀏覽器輸入電腦的 IP（例如 `http://192.168.1.xxx:8080`），即可使用並「加入主畫面」！

## 📁 檔案結構

- `index.html`：現代簡約的行動端/桌面端介面
- `style.css`：專屬綠意清爽排版樣式
- `app.js`：排程演算法、字數均分計算、LocalStorage 狀態記憶
- `books.js`：66 卷新舊約生命讀經資料庫
- `server.py`：輕量 Python 本機伺服器與 CORS 代理
- `manifest.json` & `sw.js`：PWA 離線支援與安裝配置
- `icons/icon.svg`：專屬生命讀經萌芽圖示
